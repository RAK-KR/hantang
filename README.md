# 한탕 (HANTANG)

PS1 레트로 스타일 1인칭 잠입 강도 게임.
밤의 든든은행 금정지점에 숨어 들어가 카드키(지점장실) → 금고 → 돈가방 4개 → 정문/뒷문 탈출.
경비 3명(로비 순찰, 직원 구역 순찰, 경비실에서 조는 경비)과 CCTV 3대. 공범 덕배는 밖에서 무전으로 (틀린) 정보를 줍니다.

### 잠입 규칙
- 어두운 곳·앉은 자세는 덜 보임(화면 아래 '노출도'), 손전등에 비치면 훤히 보임
- 뛰는 발소리, 칼 딸깍 소리, 춤 음악은 경비가 들음
- 경비 머리 위 ?가 차면 의심 → 확인하러 옴, !면 추격 · 경찰봉 공격
- 눈치 못 챈 경비 뒤에서 E = 기절. 쓰러진 경비가 발견되면 경보
- CCTV는 경비실 단말기(E 꾹)로 끌 수 있음
- 경보가 울리면 75초 뒤 경찰 도착 = 체포

## 실행
GitHub Pages에 이 폴더 그대로 올리면 됩니다(빌드 없음, three.js는 CDN).
로컬에서 볼 때는 `index.html`을 직접 열지 말고 간단한 서버로 여세요(ES 모듈 때문에). 예: `python -m http.server`

## 조작
| 키 | 기능 |
|---|---|
| WASD / Shift / Ctrl / Space | 이동 / 달리기 / 앉기 / 점프 |
| F | 칼 펼치기·접기 |
| R | 다음 트릭(팬 회전 → 에어리얼 → 연속 플립 → 헬리콥터 → 프리스타일 콤보) |
| 1~6 | 트릭 고르기(1 팬 회전+롤오버, 2 에어리얼, 3 연속 플립(젠), 4 헬리콥터, 5 살펴보기, 6 프리스타일 콤보) |
| E (꾹) | 상호작용(카드키·금고·돈가방·서랍·CCTV) · 경비 뒤에서 기절시키기 |
| H | 키 설명 숨기기/보이기 |
| 좌클릭 | 휘두르기(접혀 있으면 펼치기) |
| G (꾹) | 감정표현 휠 – 마우스로 고르고 G를 떼면 실행(클릭도 가능, 우클릭 취소) |
| G 누른 채 1 / 2 | 휠 탭 전환(1 제스처, 2 춤) – 마우스 휠로도 가능 |
| V | 3인칭 보기 |
| Esc | 설정(마우스 감도, 해상도, 디더, 폴리곤 흔들림, 볼륨) |

## 감정표현 추가하는 법
`js/emotes.js` 맨 아래 `EMOTES` 배열에 항목을 추가합니다.
- 손 제스처: `fp`(1인칭 왼손 클립) + `body`(전신 클립)
- 전신 동작: `tp: true` + `body` (카메라가 앞으로 빠져서 보여 줌)
- 춤 추가: `js/dances.js`에 `buildDance`로 박자 목록을 만들고, `emotes.js`의 춤 탭에 `D(...)`로 등록
- 춤 음악: audio.js `STYLES`(parapara, jersey, trap, house, disco, electro, trot) – 전부 직접 합성한 오리지널 비트
